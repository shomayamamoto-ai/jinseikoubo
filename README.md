# 人生工房 Webサイト（構想デモ）

人生工房の「最終形態」をひと目で伝えるための、静的なデモサイトです。
ビルド不要で、`index.html` をブラウザで開くだけで表示できます。

## 掲載している7つのサービス

| No | サービス名（仮） | 参考にした業態 | デモでできること |
|----|----|----|----|
| 01 | インバウンドツアー | 訪日客向け体験ツアー | 地域で絞り込み |
| 02 | メタバース工房 | 仮想空間ゲーム・交流 | アバターを動かしてエリア訪問 |
| 03 | アカデミー | オンライン講座・ワークショップ | 録画／ライブで切り替え |
| 04 | 工房チャンネル | 動画投稿サイト | キーワード検索 |
| 05 | 工房シアター | 定額制の映像配信 | 横スクロールの作品一覧 |
| 06 | 工房マーケット | 個人間EC・オークション | 絞り込み・並び替え・入札（保存なし） |
| 07 | 未来研究ファンド | 研究支援クラウドファンディング | 1口1万円の支援額シミュレーター |

## デザインの考え方

- 藍染の「青海波」文様と、山吹色の目印で、日本の「工房」らしさを表現
- 7つのサービスに漢字一文字の印（旅・遊・学・発・観・市・研）を付け、どこにいるか分かりやすく
- ライト／ダーク両方の表示に対応

## 日本語／英語の切り替え

- 画面右上の「EN／日本語」ボタンで、ページ全体を切り替えられます。
- 初めて開いたとき、ブラウザの言語設定が日本語以外なら英語で表示します（訪日客向け）。
- 選んだ言語は、その端末のブラウザに記憶されます。
- 英語の文言は `assets/js/main.js` の `I18N_STATIC`（固定テキスト）と、
  各データの `en` 項目（ツアー・講座など）で管理しています。

## ファイル構成

```
index.html            … ページ本体
assets/css/style.css  … デザイン（色は :root の変数で一括変更可）
assets/js/main.js     … サンプルデータと動き
```

## 注意

- 掲載している商品・講座・案件・金額・人名はすべて架空のサンプルです。
- 申込・決済・投資・メール登録は動作しません（送信も保存もしません）。
- 研究ファンドを金銭的リターン付きで実施する場合は、金融商品取引法などの
  確認が必要になる可能性があるため、正式公開前に専門家への確認を前提としています。
